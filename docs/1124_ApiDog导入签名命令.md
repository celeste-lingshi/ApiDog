# ApiDog 导入签名命令

## 导入结果

「导入 cURL」可以读取一段常见的签名命令组合。它识别普通变量赋值、取秒级时间戳的 date、固定的 OpenSSL HMAC-SHA256 签名管道、一条 cURL 和可选的 jq 字段提取。导入只转换成请求字段，不会执行这些 Shell 命令或读取环境变量里的密钥。

地址和连接设置中的已知变量保留为请求内变量，发送时再展开。改一次主机名，URL、指定解析和代理例外一起更新。查询页保留可编辑的业务参数，并标注发送时自动加入的认证字段。认证页记录签名算法、签名路径和 Key 参数名。外部密钥变量只显示名称，值由使用者填写。发送或复制时重新生成 timestamp 和 sign，二者使用同一时间戳。

## 连接设置

连接页显示 --resolve 和 --noproxy。前者把指定域名和端口连到指定 IP，URL 的域名仍用于 Host 和 HTTPS 证书校验。后者指定哪些地址不走代理。带这两项的请求使用系统 cURL 发送，应用把结构化参数通过标准输入传入，凭证不放入进程参数。普通请求继续使用系统的 URLSession。

## 结果提取

文档中的 .reason[]?.port 会在响应的「提取」页显示每个 port，同时可以切回正文查看完整 JSON。支持 jq -r 的简单字段路径、数组遍历和可选遍历。复制出的命令保留对应的 jq 步骤。其他 Shell 写法和 jq 表达式会在导入时明确提示，不会替换当前请求。
