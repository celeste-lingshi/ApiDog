# ApiDog 保存请求与认证

旧版的「保存」会打开名称和分类弹窗，也会在写入本地文件时清掉认证值。退出后，之前填写的 API Key、密码和签名密钥需要重新输入。

「保存」直接更新当前请求。「另存为」可选分类和名称，会建立一条独立请求。首次保存时也会询问分类和名称。已有请求可从目录菜单改名或移动。

目录请求的认证值会加密写入本机工作区。新版把解密密钥放在 `~/Library/Application Support/ApiDog/workspace.key`，文件权限只允许当前账号读写。单独复制 `workspace.json` 不会带走解密密钥。同一账号下能读这两个文件的程序可以解密认证值。请求历史继续清除认证页中的密钥。

旧版启动时会到 macOS 钥匙串读取 `com.celeste-lingshi.apidog.workspace`，如果系统在等授权，窗口也会一起卡住。新版直接打开窗口。旧工作区可以浏览，原文件会保留。点「迁移认证」并允许一次钥匙串访问后，原有认证值即可继续使用。之后启动和升级都直接使用本地密钥。
