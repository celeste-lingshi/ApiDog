# ApiDog 保存请求与认证

旧版的「保存」会打开名称和分类弹窗，也会在写入本地文件时清掉认证值。退出后，之前填写的 API Key、密码和签名密钥需要重新输入。

「保存」直接更新当前请求。「另存为」可选分类和名称，会建立一条独立请求。首次保存时也会询问分类和名称。已有请求可从目录菜单改名或移动。

目录请求保存认证值，重新打开后可以继续使用。认证值加密后随请求写入本机工作区，解密用的密钥放在 macOS 钥匙串，也就是系统的凭证保管处。保存会一次写好请求配置和加密值。读取钥匙串失败时会提示，避免把原文件覆盖。请求历史继续清除认证页中的密钥。

macOS 如果询问是否允许访问 `com.celeste-lingshi.apidog.workspace`，指的是这把工作区解密密钥。本地构建的新版本可能需要重新获得访问许可。签名认证页的 Secure Key 可直接查看和编辑，保存时会加密。
