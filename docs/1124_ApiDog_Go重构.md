# ApiDog Go 重构

0.7.7 是 macOS 上的 SwiftUI 应用。Go 版继续以应用和 DMG 安装包交付。Wails 在桌面窗口内提供网页界面，界面调用 Go 代码完成发请求、认证和文件读写，无需启动任何外部服务。

## 保留的功能与外观

- 保留请求目录、历史页、搜索、保存和另存为、复制、删除确认、分类拖动及快捷键。
- 保留方法和地址、请求内变量、查询、请求头、请求体、认证、连接、cURL 导入和预览、响应正文和字段提取。
- 保留签名、JavaScript 生成认证、指定解析、跳过代理、跟随重定向和请求取消。
- 保留狗狗图标、窗口布局、字体层次、自定义下拉菜单、深色、浅色和跟随系统。窄窗口上下显示请求和响应，宽窗口左右并排。

## 数据和验证

仍在用户的 ApiDog 数据目录读取 `workspace.json` 和 `workspace.key`。用已有格式保存请求、历史和加密的认证值。旧工作区如果没有本地密钥，先读出可浏览的数据，用户主动迁移时才读取钥匙串。主题偏好沿用 macOS 上的设置。

用示例工作区做读写往返，用本机接口验证请求和认证，用浏览器自动化检查界面和关键交互。打包后再检查应用签名、图标和实际启动。验证完成前用隔离的 Git 工作目录开发。
