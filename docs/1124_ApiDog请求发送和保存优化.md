# ApiDog 请求发送和保存优化

0.8.0 的「跟随跳转」会把自定义认证头带到其他主机。源站由协议、主机名和端口共同确定。带认证的请求仍会跟随同源跳转，遇到跨源目标就保留这次跳转响应，并在响应区显示目标。复制的 cURL 只执行首跳，因为 cURL 的自动跳转选项无法限定源站。

请求目录、另存为和历史清理都以工作区文件成功写入为准。写入失败会显示错误，保留原工作区状态以及当前编辑的草稿。已收到的响应照常展示，历史写入失败单独报告。

地址栏中的原始查询会补齐 URL 编码。已有的百分号编码和查询分隔符保持原样。编辑请求时只刷新 cURL 预览，查看上次响应时保留响应区域。继续编辑会取消已经过时的预览。
