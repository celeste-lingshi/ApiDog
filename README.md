# ApiDog

轻量 macOS 接口调试工具。请求从你的 Mac 发出，可以调用本机服务和当前网络能访问的接口。

## 使用

- 选择请求方法并填写 URL。输入 `http://111/{hostname}/ping` 后，可在请求的「变量」页里填写 `hostname`。
- 在「查询」「请求头」「认证」页按字段填写，JSON 等文本可粘贴到「请求体」。
- 右侧 cURL 随编辑更新，可以复制命令。顶部「导入 cURL」可以把粘贴的命令拆成可编辑字段。
- 在左边搜索并打开最近的请求，恢复输入后可以继续修改或发送。
- 按 `⌘↩` 发送，按 `⌘N` 新建请求。发送过程中可以取消。响应支持查看状态、耗时和大小，也可以复制正文或响应头。

## 构建

需要 macOS 13 或更新版本和 Swift 5.9 或更新版本。没有需要下载的第三方依赖。

```bash
swift run
bash scripts/check.sh
bash scripts/package.sh
```

打包产物在 `dist/`。打开 DMG 后把 ApiDog 拖到「应用程序」。本地构建产物没有开发者公证，首次打开时可能需要通过 macOS 的「隐私与安全性」确认。

## 本地数据

`~/Library/Application Support/ApiDog/workspace.json` 保存最近 100 条请求的字段、请求内变量和响应摘要。响应头和正文只在当次打开的窗口里显示，最多读取 256 KiB。

认证页的密钥只保留在应用的当前运行中。直接放进 URL、普通请求头或正文的内容会随历史以明文保存。复制的 cURL 包含请求实际使用的认证信息。
