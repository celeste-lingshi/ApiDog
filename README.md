# ApiDog

轻量 macOS 接口调试工具。请求从你的 Mac 发出，可以调用本机服务和当前网络能访问的接口。

## 使用

- 选择请求方法并填写 URL。输入 `http://111/{hostname}/ping` 后，可在请求的「变量」页里填写 `hostname`。
- 在「查询」「请求头」「认证」页按字段填写，JSON 等文本可粘贴到「请求体」。认证还支持 HMAC-SHA256 和自定义 JavaScript。
- 右侧 cURL 随编辑更新，可以复制命令。顶部「导入 cURL」可以把粘贴的命令拆成可编辑字段，也支持常见的 Shell 签名片段、指定解析和 jq 字段提取。
- 左侧「请求目录」可建分类、改名或移动请求。「保存」更新当前请求，首次保存会询问名称和目录。「另存为」可以选名称和目录，建立一条独立请求。独立的「请求历史」页可搜索和重放最近的发送。
- 已在目录里的请求停笔约 600 毫秒后会自动保存。切换请求或正常退出时，会先保存还有改动的目录请求。
- 把请求拖到目标分类标题或「未分类」即可移动。每条请求右侧可以复制或删除。
- 按 `⌘↩` 发送，按 `⌘S` 保存请求。发送过程中可以取消。响应支持查看状态、耗时和大小，也可以复制正文或响应头。
- 按 `⌘Q` 或 `⌥Q` 退出 ApiDog。

## 构建

需要 macOS 13 或更新版本、Go 1.25.8 或更新版本，以及 Xcode 命令行工具。界面资源随 Go 二进制打包，Wails 使用系统的 WebKit 渲染。定向检查还需要 Node.js。

```bash
go run -tags production .
bash scripts/check.sh
bash scripts/package.sh
```

打包产物在 `dist/`。打开 DMG 后把 ApiDog 拖到「应用程序」。本地构建产物没有开发者公证，首次打开时可能需要通过 macOS 的「隐私与安全性」确认。

## 本地数据

`~/Library/Application Support/ApiDog/workspace.json` 保存请求目录和最近 50 条请求历史。点击新记录可以查看当时的响应头、正文和提取结果，正文最多读取 256 KiB。旧记录可以继续打开请求和已有的响应摘要。

目录中的请求会保留认证页的密钥。认证值加密保存，解密密钥放在同一目录里仅当前账号可读写的 `workspace.key`。旧版的钥匙串密钥可在应用内迁移一次。请求历史会清除认证页的密钥。直接放进 URL、普通请求头或正文的内容会随历史以明文保存。复制的 cURL 包含请求实际使用的认证信息。
