# ApiDog

轻量 macOS 接口调试工具。请求从你的 Mac 发出，可以调用本机服务和当前网络能访问的接口。

## 使用

- 输入 URL、请求头和文本正文，选择请求方法后发送。请求头每行一个，例如 `Content-Type: application/json`。
- 在「变量」里建立环境。在 URL、请求头值和正文中用 `{{baseUrl}}` 这样的占位符，发送时替换成当前环境的值。
- 在左边打开最近的请求，恢复输入后可以继续修改或发送。
- 按 `⌘↩` 发送，按 `⌘N` 新建请求。支持查看响应状态、耗时、正文和响应头。

## 构建

需要 macOS 13 或更新版本和 Swift 5.9 或更新版本。没有需要下载的第三方依赖。

```bash
swift run
bash scripts/check.sh
bash scripts/package.sh
```

打包产物在 `dist/`。打开 DMG 后把 ApiDog 拖到「应用程序」。本地构建产物没有开发者公证，首次打开时可能需要通过 macOS 的「隐私与安全性」确认。

## 本地数据

`~/Library/Application Support/ApiDog/workspace.json` 保存环境变量、最近 100 条请求模板和响应摘要。历史恢复的是原始占位符，重发时使用当前环境。响应头和正文只在当次打开的窗口里显示，最多读取 256 KiB。

直接填入的变量和请求内容会随工作区明文保存。临时 Token 可以放进普通占位符，在对应环境变量上勾选「仅本次运行」。这种变量的值会在退出后清空，名称会保留。
